# 🎬 After Effects SRT Importer

A lightweight Adobe After Effects script to import `.srt` subtitle files as perfectly timed text layers.

Designed for lyric videos, subtitle editing, and motion graphics workflows — simple, fast, and beginner-friendly.

🚀 Features

* 📥 Import `.srt` subtitle files directly into After Effects
* ⏱ Automatically converts timestamps to layer timing
* 📝 Creates individual text layers for each subtitle
* 🎯 Centers text in composition
* 📄 Supports multi-line subtitles
* ⚡ Fast and easy workflow

## 📦 Installation

1. Download the script:

   ```
   ae-srt-importer.jsx
   ```

2. Move it to:

   ```
   After Effects > Support Files > Scripts > ScriptUI Panels
   ```

3. Restart Adobe After Effects

---

## ▶️ Usage

1. Open After Effects
2. Create or open a composition
3. Go to:

   ```
   Window → ae-srt-importer
   ```
4. Select your `.srt` file

🎉 Your subtitles will be imported as timed text layers!
